## 🔄 更新纹理数据说明
本工具默认通过国内 Gitee 仓库拉取纹理配置文件。若网络环境无法访问 Gitee，可按以下步骤切换至 GitHub 源：
1. 打开 `setting.json`
2. **完整删除** `"config_repository_url": "https://gitee.com/..."` 这一行（注意：删除后需确保上下行衔接处**无多余逗号**，保持合法 JSON 格式）
3. 保存文件并重启工具，程序将自动回退至 GitHub 仓库

💡 提示：修改后建议使用在线 JSON 校验工具检查语法，避免配置文件损坏导致工具无法启动。
