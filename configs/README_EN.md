# Configuration File Guide

## Configuration File Selection

- `config.json` - CN Server Configuration
- `config_ASIA.json` - JP Server Configuration

## Manual Download

Due to frequent access limitations on GitHub/Gitee, automatic downloads may fail. If this happens, follow these steps to manually configure:

1. Select the configuration file corresponding to your server
2. Download the configuration file to the application root directory

## Important Notes

- The tool defaults to accessing Gitee for configuration file downloads
- International users should remove the `config_repository_url` field from `setting.json` to access GitHub
